# VIGILO · tendências de criativos

Pesquisa de tendências de criativos para Meta Ads (Facebook e Instagram), usada pela aba **Criativos → Ideias e tendências** do painel VIGILO.

- `tendencias.json` é atualizado automaticamente toda segunda, quarta e sexta.
- O painel baixa este arquivo e guarda uma cópia local para usar sem internet.
- Não contém dados de clientes nem de contas de anúncio.
